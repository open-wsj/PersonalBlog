> 这是一篇自己整理的机器学习笔记。主题是最基础的优化算法——**梯度下降（Gradient Descent）**。模型、损失、优化器这三件套里，梯度下降属于第三件，但它常常被当成「一行 `opt.step()`」带过，公式背后的直觉反而没人讲。

### 一、梯度下降在解决什么问题

训练一个模型，本质上是找一个参数 $\theta$，让损失函数 $J(\theta)$ 尽量小：

$$
\theta^{\ast} = \arg\min_{\theta} J(\theta)
$$

$J$ 通常没有解析解（能直接令导数为零解出来的情况很少），所以只能迭代着往最小值挪。梯度下降给出的答案非常朴素：

> 在当前点算出 $J$ 下降最快的方向，朝那个方向走一小步，重复。

$$
\theta_{t+1} = \theta_t - \eta\, \nabla_\theta J(\theta_t)
$$

-   $\nabla_\theta J(\theta_t)$ 是梯度，指向 $J$ **增长最快**的方向
-   负号表示往反方向走，即下降最快的方向
-   $\eta$ 是学习率，控制每步走多远

一句话概括：**沿负梯度方向前进，直到走不动为止。**

### 二、为什么沿负梯度走一定会下降

这个结论不是经验，可以用一阶泰勒展开证明。设步长为 $\eta$，则

$$
J(\theta - \eta g) \approx J(\theta) - \eta\, g^\top g = J(\theta) - \eta \lVert g \rVert^2
$$

其中 $g = \nabla J(\theta)$。只要 $\eta > 0$ 且 $g \neq 0$，就有 $\lVert g \rVert^2 > 0$，于是 $J(\theta - \eta g) < J(\theta)$。

由此看出两件事：

1.  **负梯度方向是局部下降最快的方向**。在所有长度相同的方向里，$-\frac{g}{\lVert g\rVert}$ 使 $g^\top d$ 最小，这就是「最速下降」这个名字的来源。
2.  **步长必须足够小**。上面的等式是一阶近似，$\eta$ 大了近似就失效，实际函数值可能反而上升。这就是学习率存在上限的理论原因。

一个常见误解：负梯度方向是**局部**最速下降方向，但对**整体**路径来说并不一定最省步。在很扁的椭圆等高线上，梯度法会来回锯齿，路径远长于理论最优——这也是后来牛顿法、动量、自适应方法出现的动机。

### 三、学习率：唯一但致命的超参数

学习率 $\eta$ 太大太小都有明确的症状：

| $\eta$ 的情况 | 现象 |
| --- | --- |
| 太大 | 损失先降后升、来回震荡、数值溢出成 `nan` |
| 偏大 | 损失在最小值附近持续抖动，降不下去 |
| 合适 | 前期快速下降，后期平缓收敛 |
| 太小 | 下降单调但极慢，迭代很多轮还离最优点很远 |

取值的实操办法：

1.  **先粗扫**：$10^{-1}, 10^{-2}, \dots, 10^{-6}$ 各跑几十步，挑 loss 降得最快且不发散的。
2.  **再微调**：在她附近按 3 倍或 10 倍间隔细扫，观察 loss 曲线形状。
3.  **最后衰减**：收敛后期如果一直抖动，说明学习率偏大，用衰减收尾。

常用的衰减方式：

$$
\eta_t = \frac{\eta_0}{1 + kt}
\quad\text{（逆时衰减）}
$$

以及阶梯衰减（每若干 epoch 乘 0.1）和余弦退火。前期大步走、后期小步微调，是让梯度下降稳定落到好解的关键。

### 四、凸与非凸：收敛保证的边界

**凸函数**（如线性回归的 MSE、逻辑回归的交叉熵）只有一个全局最小值，梯度下降的理论性质很干净：

-   固定学习率足够小时，每步都保证 $J$ 严格下降
-   在 $L$-平滑（梯度变化有上界 $L$）条件下，$\eta \le 1/L$ 可保证收敛
-   收敛速度约为 $O(1/t)$，即误差随迭代次数倒数衰减

**非凸函数**（绝大多数神经网络）就没有这种保证：

-   可能停在局部极小值
-   更常见的是停在**鞍点**和平坦区域——梯度接近 0，但并不是极小值
-   此时只能保证收敛到某个驻点（梯度为 0 的点）

不过实践中有个安慰性结论：高维空间里真正的局部极小值其实很罕见，大量「看起来卡住」的位置是鞍点。梯度下降卡住时，加一点随机扰动或用动量往往就能继续走，这也是随机梯度下降（SGD）在实践中反而更有优势的原因之一。

### 五、NumPy 手写一版

用线性回归 $y = Xw + b$、均方误差来验证。损失与梯度为：

$$
J(w) = \frac{1}{N}\sum_{i=1}^{N}(\hat{y}_i - y_i)^2,
\qquad
\nabla_w J = \frac{2}{N} X^\top (Xw - y)
$$

```python
import numpy as np

rng = np.random.default_rng(42)
n, d = 500, 5
X = rng.normal(size=(n, d))
true_w = rng.normal(size=d)
y = X @ true_w + 3.0 + rng.normal(scale=0.1, size=n)

X_b = np.c_[np.ones(n), X]      # 加一列 1，把偏置并入权重
w = np.zeros(d + 1)

lr, epochs = 0.1, 200
losses = []

for t in range(epochs):
    grad = 2.0 / n * X_b.T @ (X_b @ w - y)   # 全量梯度
    w -= lr * grad
    losses.append(np.mean((X_b @ w - y) ** 2))

print("学到的偏置:", round(w[0], 3))     # 应接近 3.0
print("初始 / 最终 MSE:", round(losses[0], 4), round(losses[-1], 6))
print("最后 10 轮 loss:", np.round(losses[-10:], 6))
```

跑完能看到两个特征：loss 单调下降；最后若干轮几乎不再变化，说明已经贴近最优点。如果 loss 抖动或上升，把 `lr` 调小再看。

观察学习率影响的最快方式，是把循环包成一个函数，对几组 `lr` 各画一条曲线：

```python
import matplotlib.pyplot as plt

for lr in [0.01, 0.1, 0.5, 1.0]:
    w = np.zeros(d + 1)
    hist = []
    for _ in range(100):
        grad = 2.0 / n * X_b.T @ (X_b @ w - y)
        w -= lr * grad
        hist.append(np.mean((X_b @ w - y) ** 2))
    plt.plot(hist, label=f"lr={lr}")

plt.yscale("log")
plt.xlabel("iteration")
plt.ylabel("MSE")
plt.legend()
plt.show()
```

$lr=0.01$ 那条会明显慢，$lr=1.0$ 往往震荡甚至发散，中间那条最快且平稳——这就是学习率扫描的直观依据。

### 六、实践中的几个坑

**1. 梯度公式里的系数算错**

$(xw - y)^2$ 求导是 $2x(xw-y)$，漏掉这个 $2$ 不会让训练失败，只是把有效学习率缩小一半，但会让你对「梯度量级」形成错误判断，换损失函数时容易翻车。

**2. 特征没标准化**

如果不做标准化，各维度尺度差很多时，等高线会变成极扁的椭圆，梯度方向几乎垂直于最优方向，于是来回锯齿、收敛极慢。**梯度下降前先做标准化，比调任何超参数都有效。**

**3. 用训练损失判断收敛**

训练损失在最优附近的小幅抖动是正常的，别一看到抖动就以为没收敛。更可靠的是看验证集指标的滑动平均，并配合早停。

**4. 固定学习率跑到黑**

前期需要大步长、后期需要小步长，一个固定值必然在某一阶段不合适。至少加一个简单的衰减。

**5. 初始化想当然**

全零初始化对线性模型没问题，但对神经网络会导致同层神经元梯度完全一样（对称性无法打破），必须用随机初始化。

### 七、和随机梯度下降的关系

梯度下降有一个现实的硬伤：**每走一步都要遍历全部 $N$ 个样本**。数据量一大，一步的代价就无法接受。

于是有了两个变体：

-   **随机梯度下降（SGD）**：每次只用 1 个样本估计梯度
-   **小批量梯度下降（mini-batch GD）**：每次用 $B$ 个样本

它们的更新式和梯度下降完全一样，只是把全量梯度 $g$ 换成了**无偏估计** $\hat{g}$。代价是引入了方差，好处是每步极便宜、并且噪声有助于逃离鞍点。实践中说的「SGD」通常指 mini-batch 版本。

理解这一点之后，Momentum、Adam 那些优化器都只是在这个更新式上继续加料（历史梯度累积、按维度缩放学习率），主干仍然是「沿负梯度走」。

### 总结

-   梯度下降的更新式只有一行：$\theta \leftarrow \theta - \eta \nabla J(\theta)$，方向由负梯度决定，步长由学习率决定。
-   沿负梯度下降可以被一阶泰勒展开严格证明，前提是步长足够小、局部足够光滑。
-   凸问题有收敛保证（$O(1/t)$），非凸问题只保证到驻点，卡住多半是鞍点。
-   代码里的四个关键细节：梯度系数别漏、特征先标准化、每个样本都参与一次全量计算、学习率要扫要衰减。
-   SGD 和 mini-batch 只是把全量梯度换成抽样估计，方向逻辑没变。

梯度下降本身五分钟能写完，真正花时间的是看 loss 曲线、判断是学习率问题还是数据问题。多跑几组对照、把曲线画出来，比推导十遍公式都管用。
